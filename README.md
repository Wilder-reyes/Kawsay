## About

*Kawsay* (“good life”) was developed as a collaborative student project during the COVID-19 period. It explored a web interface intended to connect **low-income schools, hospitals, and neighborhoods** with potential donors who could provide essential supplies.

The repository preserves the original educational prototype. **It is not presented as an actively operating donation or relief service.**

## What the prototype includes

- A responsive landing page introducing the community-support idea.
- Sections for project information, team, and a COVID-19 map.
- Donation and participation calls to action with external links.
- Frontend code based on HTML, CSS, JavaScript, Bootstrap, and jQuery.
- An accompanying experimental Python/Firebase authentication script.

This prototype should be treated as educational and historical. The included Firebase client configuration does **not** make it suitable for live authentication deployment without a fresh security review, access-rule audit, and replacement of outdated dependencies.
